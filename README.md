# Tinkoff Invest → Google Sheets

Автоматический перенос портфеля из Тинькофф Инвестиций в Google Таблицу.
Работает **автономно в облаке** — ваш компьютер может быть выключен.

**Что вы получите:**

- Google-таблицу с полным состоянием портфеля: позиции, разбивка по типам, отраслям, деньги.
- Годовой отчёт с пассивным доходом (дивиденды, купоны), комиссиями, налогами.
- Точную доходность портфеля (**XIRR** + простая).
- Историю всех операций и ежедневные снимки стоимости портфеля.
- **Автообновление каждые 15 минут** прямо из GitHub — без вашего участия.

## Как это выглядит

```
📊 Мой портфель

💼 Всего активов:        127 631 ₽
💵 Свободные деньги:         91 ₽
📈 Позиций:                  43

📉 Доходность
   Простая, %:              -5.00
   XIRR за всё время, %:   -18.21

💰 Дивиденды за год:      5 846 ₽
📈 Купоны за год:         1 400 ₽
```

## Что создаётся в таблице

| Лист | Что содержит |
|---|---|
| `Positions` | Сырые позиции по каждому счёту, с НКД по облигациям |
| `Positions_Aggregated` | Все позиции, сгруппированные по названию |
| `Positions_Shares` | Только акции |
| `Positions_Bonds` | Только облигации |
| `Positions_ETFs` | Только фонды |
| `Positions_Currencies` | Только валюты |
| `Positions_Futures` | Только фьючерсы |
| `Positions_Other` | Всё остальное |
| `Positions_Money` | Свободные деньги в рублях |
| `Positions_SummaryByType` | Итоговая сумма по каждой категории |
| `Operations` | Все операции за 3 года (покупки, продажи, дивиденды, налоги) |
| `Report` | Годовой отчёт: дивиденды, купоны, комиссии, XIRR, простая доходность |
| `PortfolioSnapshots` | Ежедневные снимки стоимости портфеля (накапливается) |

## Зачем нужен такой подход

Google Apps Script **не может** напрямую обращаться к Tinkoff Invest API: сертификат
Минцифры РФ не входит в доверенные в среде Apps Script, а параметр
`validateHttpsCertificates: false` эту проблему не решает.

Используется двухслойная схема:

1. **Python-скрипт** получает данные через официальный SDK
   [`t-tech-investments`](https://opensource.tbank.ru/invest/), в котором сертификат
   уже встроен.
2. Скрипт отправляет данные POST-запросом в **Apps Script**.
3. Apps Script раскладывает данные по листам Google Таблицы.

## Требования

- **Аккаунт Тинькофф Инвестиций** (для токена API)
- **Аккаунт Google** (для таблицы)
- **Аккаунт GitHub** (для автономного режима)

Для локального запуска:

- Windows 10/11, macOS или Linux
- Python 3.11 или новее ([скачать](https://www.python.org/downloads/))
  - При установке поставьте галочку **«Add Python to PATH»**

## 🚀 Автономный режим (рекомендуется)

Скрипт работает **на серверах GitHub** каждые 15 минут. Ваш компьютер не нужен.

### Шаг 1. Форкнуть репозиторий

1. Откройте [репозиторий проекта](https://github.com/ivanermolenko61-commits/tinkoff-to-gsheets).
2. Нажмите **Fork** (справа сверху).
3. У вас появится **своя копия** проекта.

### Шаг 2. Создать токен Тинькофф

1. Личный кабинет Тинькофф Инвестиций → **Настройки → Токены для API**.
2. Создайте новый токен. **Тип доступа: только чтение.**
3. Скопируйте токен (`t.xxxxxxxxxxxxxxxxxxxxxxxxx`).

> ⚠️ Токен показывается **один раз**. Потеряете — создадите новый.

### Шаг 3. Создать Google Таблицу

1. Откройте [sheets.google.com](https://sheets.google.com/), создайте пустую таблицу.
2. Дайте имя, например, «Инвестиции».
3. **Удалите стандартный лист `Sheet1`** — остальные создадутся автоматически.

### Шаг 4. Настроить Apps Script

1. В таблице: **Расширения → Apps Script**.
2. **Ctrl+A → Delete** — удалите всё содержимое.
3. Откройте файл `apps_script.js` из репозитория и **скопируйте его в редактор**.
4. **Ctrl+S**, назовите проект `InvestSync`.
5. Слева — **⚙️ Настройки проекта**.
6. Раздел **«Свойства скрипта»** → **«Добавить свойство скрипта»**:
   - **Имя**: `APPS_SECRET`
   - **Значение**: придумайте секрет, например `MyInvestSecret2026x9k2`
     (запишите его — понадобится дальше).
7. Сохраните.

### Шаг 5. Опубликовать как веб-приложение

1. **Развернуть → Новое развертывание**.
2. Тип: **Веб-приложение** (нажмите шестерёнку → выбрать).
3. Заполните:
   - **Описание**: `v1`
   - **Запуск от имени**: **Я**
   - **Кто имеет доступ**: **Все**
4. **Развернуть** → пройдите разрешения (может появиться «Google не проверил приложение» — нажмите **«Дополнительные настройки → Перейти на страницу (небезопасно)»**).
5. **Скопируйте URL** — оканчивается на `/exec`.

### Шаг 6. Добавить секреты в GitHub

1. В **своём форке** на GitHub: **Settings → Secrets and variables → Actions**.
2. **New repository secret** — три раза:

   | Имя | Значение |
   |---|---|
   | `TINKOFF_TOKEN` | Ваш токен из шага 2 |
   | `APPS_SCRIPT_URL` | URL из шага 5 |
   | `APPS_SCRIPT_SECRET` | Секрет из шага 4 |

**Важно:** имена должны быть точно такими. Значения — без префиксов, без кавычек.

### Шаг 7. Запустить

1. Вкладка **Actions** в вашем форке.
2. Слева выберите **Tinkoff Invest Sync**.
3. Нажмите **Run workflow → Run workflow** (зелёная кнопка).
4. Через 1–2 минуты увидите зелёную галочку ✅.

Откройте Google Таблицу — данные появятся автоматически. Дальше скрипт будет
запускаться **сам каждые 15 минут**.

## 💻 Локальный режим (для разработки)

Если нужно запустить локально, чтобы посмотреть/отладить.

### Шаг 1. Склонировать

```bash
git clone https://github.com/ivanermolenko61-commits/tinkoff-to-gsheets.git
cd tinkoff-to-gsheets
```

### Шаг 2. Установить зависимости

**Windows:**
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

**macOS/Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### Шаг 3. Создать `.env`

1. Скопируйте `.env.example` в `.env`.
2. Заполните:

```
TINKOFF_TOKEN=t.ваш_токен
APPS_SCRIPT_URL=https://script.google.com/macros/s/ВАШ_ID/exec
APPS_SCRIPT_SECRET=ваш_секрет
```

### Шаг 4. Запустить

```bash
python invest.py
```

Или **двойной клик по `run.bat`** (Windows).

**Успешный результат:**

```
Открытых счетов: 3
  · Обработка счёта #1...
    позиций: 43
...
HTTP статус: 200
Готово. Все листы обновлены.
```

## 📊 Годовой отчёт (`YearReport`)

| Показатель | Что означает |
|---|---|
| Дивиденды, купоны | Доход за последние 365 дней |
| Комиссии, налоги | Расходы за последние 365 дней |
| Пассивный доход | Дивиденды + купоны − комиссии − налоги |
| Результат в рублях | Портфель сейчас − вложено (нетто) |
| **Простая доходность, %** | Результат / Внесено × 100 |
| **XIRR за всё время** | Точная годовая доходность с учётом дат потоков |
| **XIRR за 365 дней** | Точная доходность за скользящий год (когда накопятся снимки) |

### Разница между простой и XIRR

- **Простая доходность** — «сколько я заработал в рублях». Не зависит от даты пополнений.
- **XIRR** — «насколько эффективно работали деньги с учётом времени». Наказывает за
  недавние крупные вложения, которые ещё не успели отработать.

Подробное объяснение — в [Wiki проекта](https://github.com/ivanermolenko61-commits/tinkoff-to-gsheets/wiki).

## 📅 Расписание

По умолчанию — **каждые 15 минут**. Изменить можно в файле
`.github/workflows/sync.yml`:

```yaml
on:
  schedule:
    - cron: '*/15 * * * *'   # каждые 15 минут
```

Примеры cron:

| Что хотите | Выражение |
|---|---|
| Каждые 15 минут | `*/15 * * * *` |
| Раз в час | `0 * * * *` |
| Раз в день в 09:00 МСК | `0 6 * * *` |
| По будням в 10:00 МСК | `0 7 * * 1-5` |

⚠️ **Cron GitHub Actions может задерживаться** на 5–15 минут при высокой нагрузке.
Это не баг — так работает очередь GitHub.

## 🔒 Безопасность

- **Токен Тинькофф** хранится только в `.env` (локально) или в **GitHub Secrets** (в облаке).
- В публичный репозиторий токен **не попадает** — `.env` в `.gitignore`.
- В логах GitHub Actions секреты заменяются на `***` автоматически.
- Используйте токен с правами **только на чтение** — даже при утечке
  никто не сможет торговать вашими средствами.

## 🛠 Решение проблем

**`ModuleNotFoundError: No module named 't_tech'`**
Зависимости не установлены. Выполните `pip install -r requirements.txt`.

**`Не задан TINKOFF_TOKEN`**
Файл `.env` не создан, пустой, или не в той папке.

**`Apps Script вернул HTTP 404`**
URL веб-приложения изменился. Переразверните Apps Script
(**Управление развертываниями → Новая версия**) и обновите `APPS_SCRIPT_URL`.

**`Invalid secret`**
`APPS_SCRIPT_SECRET` в `.env` не совпадает с `APPS_SECRET` в Script Properties.

**`SSL Error` в Apps Script**
Нормально — именно поэтому используется Python (см. раздел «Зачем нужен такой подход»).

**`rate limit` от Tinkoff API**
Уменьшите частоту запуска в `sync.yml` (например, `0 * * * *` — раз в час).
