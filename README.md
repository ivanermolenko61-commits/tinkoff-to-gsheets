# Tinkoff Invest → Google Sheets

Автоматический перенос портфеля из Тинькофф Инвестиций в Google Таблицу.
Работает на Windows, запускается одной командой.

**Что вы получите:** Google-таблицу с вашими позициями, разбитыми по типам
(акции, облигации, фонды и т.д.), с суммами в рублях и средней ценой покупки.

## Как это выглядит

```
Позиции            │ Кол-во │ Ср. цена │ Стоимость
───────────────────┼────────┼──────────┼───────────
Сбербанк           │  100   │  250.30₽ │ 25 030.00₽
Газпром            │   50   │  180.15₽ │  9 007.50₽
...
```

## Требования

- **Windows 10 или 11**
- **Python 3.11 или новее** ([скачать](https://www.python.org/downloads/))
  - При установке **обязательно** поставьте галочку **«Add Python to PATH»**
- **Аккаунт Тинькофф Инвестиций**
- **Аккаунт Google** (для таблицы)

## Пошаговая установка

### Шаг 1. Скачать проект

**Вариант А — через Git** (если установлен):

```bash
git clone https://github.com/ivanermolenko61-commits/tinkoff-to-gsheets.git
cd tinkoff-to-gsheets
```

**Вариант Б — без Git:** на странице репозитория нажмите зелёную кнопку
**Code → Download ZIP**, распакуйте архив в удобное место (например, `C:\Projects\`).

### Шаг 2. Создать токен Тинькофф

1. Зайдите в личный кабинет Тинькофф Инвестиций.
2. **Настройки → Токены для API** (или «Для приложений»).
3. Создайте новый токен. **Тип доступа: только чтение.**
4. Скопируйте токен — он выглядит как `t.xxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
   Сохраните его в блокнот — он понадобится дальше.

> ⚠️ Токен показывается один раз. Если потеряете — создайте новый.

### Шаг 3. Создать Google Таблицу

1. Откройте [sheets.google.com](https://sheets.google.com/).
2. Создайте пустую таблицу (кнопка «+»).
3. Дайте ей имя — например, «Инвестиции».
4. **Удалите стандартный лист «Sheet1»** (или «Лист1»), который Google создаёт
   автоматически: правый клик по ярлычку внизу → Удалить.
   Остальные листы программа создаст сама при первом запуске.

### Шаг 4. Настроить Apps Script

Этот шаг нужен, чтобы Python-скрипт мог записывать данные в вашу таблицу.

1. **В той же Google Таблице:** меню **Расширения → Apps Script**.
2. Откроется редактор кода. **Выделите всё (Ctrl+A) и удалите.**
3. Откройте файл `apps_script.js` из скачанного проекта в любом редакторе
   (Блокнот, VS Code) и **скопируйте его содержимое**.
4. **Вставьте** скопированный код в редактор Apps Script.
5. Нажмите **Ctrl+S** (сохранить). Придумайте имя проекту — например, `InvestSync`.
6. В левой панели нажмите иконку **⚙️ (Настройки проекта)**.
7. Прокрутите до раздела **«Свойства скрипта»** → **«Добавить свойство скрипта»**.
8. Заполните:
   - **Имя**: `APPS_SECRET`
   - **Значение**: придумайте любой секрет, например `MyInvestSecret2026x9k2`
     (это просто строка для защиты — запишите её, она понадобится дальше).
9. Нажмите **«Сохранить свойства скрипта»**.

### Шаг 5. Опубликовать Apps Script как веб-приложение

1. В редакторе Apps Script: **Развернуть → Новое развертывание**.
2. Нажмите на иконку шестерёнки рядом с «Тип» → выберите **«Веб-приложение»**.
3. Заполните:
   - **Описание**: `v1`
   - **Запуск от имени**: **Я** (`ваш-email@gmail.com`)
   - **Кто имеет доступ**: **Все**
4. Нажмите **«Развернуть»**.
5. Google попросит разрешения → **«Разрешить доступ»**.
   Может появиться предупреждение «Google не проверил это приложение» —
   нажмите **«Дополнительные настройки» → «Перейти на страницу … (небезопасно)»**.
   Это нормально: приложение ваше, и вы даёте ему доступ сами.
6. **Скопируйте URL веб-приложения** — он заканчивается на `/exec`.
   Сохраните в блокнот.

### Шаг 6. Установить зависимости проекта

Откройте терминал (в VS Code или cmd), перейдите в папку проекта:

```bash
cd путь\к\папке\проекта
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### Шаг 7. Создать файл `.env` с секретами

1. В папке проекта найдите файл `.env.example`.
2. **Скопируйте его** и переименуйте копию в `.env` (без `.example`).
3. Откройте `.env` в Блокноте и заполните значения:

```
TINKOFF_TOKEN=t.ваш_токен_из_шага_2
APPS_SCRIPT_URL=https://script.google.com/macros/s/.../exec
APPS_SCRIPT_SECRET=MyInvestSecret2026x9k2
```

- `TINKOFF_TOKEN` — из шага 2.
- `APPS_SCRIPT_URL` — из шага 5.
- `APPS_SCRIPT_SECRET` — тот же, что указали в шаге 4 (пункт 8).

Сохраните файл.

### Шаг 8. Запустить

```bash
python invest.py
```

Или просто **двойной клик по `run.bat`** в Проводнике Windows.

**Успешный результат** — в терминале появится:

```
Открытых счетов: 3
  · Обработка счёта #1...
    позиций: 43
  · Обработка счёта #2...
    позиций: 0
Собрано строк: 44
Готово. Все листы обновлены.
```

Откройте Google Таблицу — данные появятся на листах автоматически.

## Что создаётся в таблице

| Лист | Что содержит |
|---|---|
| `Positions` | Сырые позиции по каждому счёту отдельно |
| `Positions_Aggregated` | Все позиции, сгруппированные по названию |
| `Positions_Shares` | Только акции |
| `Positions_Bonds` | Только облигации |
| `Positions_ETFs` | Только фонды |
| `Positions_Currencies` | Только валюты |
| `Positions_Futures` | Только фьючерсы |
| `Positions_Other` | Всё остальное |
| `Positions_Money` | Свободные деньги в рублях |
| `Positions_SummaryByType` | Итоговая сумма по каждой категории |

## Как часто обновлять

Запускайте `invest.py` вручную, когда нужно обновить данные.
Можно повесить на **Планировщик задач Windows**, чтобы работало автоматически
по расписанию — см. раздел ниже.

## Автоматический запуск по расписанию (опционально)

1. Откройте **Планировщик задач** Windows (поиск в меню Пуск).
2. **Создать задачу** → вкладка **Триггеры** → **Создать** → «По расписанию».
   - Например, каждый день в 10:00.
3. Вкладка **Действия** → **Создать** → **Запуск программы**:
   - **Программа**: `C:\путь\к\проекту\run.bat`
4. Сохраните. Теперь скрипт запускается автоматически, когда компьютер включён.

## Решение проблем

**`ModuleNotFoundError: No module named 't_tech'`**
Зависимости не установлены. Выполните `pip install -r requirements.txt`
в активированном `.venv`.

**`Не задан TINKOFF_TOKEN в .env`**
Файл `.env` не создан, пустой, или сохранён в неправильной кодировке.
Проверьте, что он в одной папке с `invest.py` и содержит строку с токеном.

**`Apps Script вернул HTTP 404`**
URL веб-приложения изменился. Переразверните Apps Script (**Развернуть →
Управление развертываниями → Новая версия**) и обновите `APPS_SCRIPT_URL` в `.env`.

**`Invalid secret`**
Значение `APPS_SCRIPT_SECRET` в `.env` не совпадает с `APPS_SECRET`
в Script Properties Apps Script. Проверьте оба значения.

**`SSL Error` в Apps Script**
Нормально — именно поэтому используется Python (см. раздел «Зачем нужен такой подход»).

## Зачем нужен такой подход

Google Apps Script не может напрямую обращаться к Tinkoff Invest API:
сертификат Минцифры РФ не входит в доверенные в среде Apps Script, а параметр
`validateHttpsCertificates: false` эту проблему не решает. Поэтому используется
двухслойная схема:

1. **Python-скрипт** локально получает данные через официальный SDK
   [`t-tech-investments`](https://opensource.tbank.ru/invest/), в котором сертификат
   уже встроен.
2. Скрипт отправляет данные POST-запросом в **Apps Script**.
3. Apps Script раскладывает данные по листам Google Таблицы.

## Безопасность

- Токен Тинькофф хранится **только** в файле `.env`, который не публикуется в Git.
- Используйте токен с правами **только на чтение** — тогда даже при утечке
  никто не сможет торговать вашими средствами.
- URL Apps Script и секрет тоже хранятся в `.env`, а не в исходном коде.
